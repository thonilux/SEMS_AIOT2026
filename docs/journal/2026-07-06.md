## 5. Investigasi W5500 LAN Tidak Connect

LAN tidak bisa mendapat IP sama sekali setelah pergantian chip. Langkah debug:

| Percobaan | Hasil |
|---|---|
| Ganti DHCP server (router berbeda) | Tetap tidak connect |
| Buka `/serial` WebSerial untuk melihat log | Tidak ada output `[ETH]` link/IP |
| Tambah IRQ pin (GPIO27) di `ETH.begin()` | Tidak berubah |
| Extend reset timing: 100ms LOW, 250ms settle | Tidak berubah |
| Ubah `phy_addr` dari `-1` ke `1` | Tidak berubah |

**Dugaan:** Kemungkinan koneksi SPI ke W5500 longgar/rusak saat proses ganti chip, atau W5500 module turut bermasalah.

### Perubahan ETH.begin()

```cpp
// Sebelum
ETH.begin(ETH_PHY_W5500, -1, kEthCs, -1, kEthRst, SPI)

// Sesudah
ETH.begin(ETH_PHY_W5500, 1, kEthCs, kEthIrq, kEthRst, SPI)
```

IRQ pin `kEthIrq = 27` sekarang aktif (event-driven, bukan polling).

## 6. WebSerial — Terminal di Browser

Implementasi serial monitor via web tanpa USB:

### Arsitektur
- **Ring buffer** 80 baris (`wsLines[80]`), sequence counter `wsSeq`
- **`wlog(fmt, ...)`**: wrapper yang menulis ke `Serial.println()` + ring buffer + timestamp `[HH:MM:SS.mmm]`
- Digunakan di event handler ETH dan WiFi (menggantikan `Serial.printf`)

### Endpoint
- `GET /serial` — terminal HTML (dark theme, monospace)
- `GET /api/serial?since=N` — JSON polling, returns `{"seq": N, "lines": [...]}`

### UI
- Background hitam terminal `#010409`, teks hijau `#3fb950`
- Color coding: ETH = biru, WiFi = ungu, MQTT = kuning, error = merah
- Auto-scroll checkbox, tombol Clear
- Poll setiap 500ms via `fetch('/api/serial?since=N')`
- Max 500 baris di DOM sebelum trimmed

## 7. LAN-First Boot Sequence

Saat boot, sebelum WiFi STA dimulai, firmware menunggu LAN dulu:

```
ETH.begin()
  └─ Tunggu ethLink (cable) maks 2 detik
       ├─ Ada kabel → tunggu ethReady (DHCP) maks 6 detik
       │    ├─ Dapat IP → wlog("[Boot] LAN ready") → lanjut WiFi sebagai backup
       │    └─ Timeout DHCP → wlog("[Boot] LAN DHCP timeout") → lanjut WiFi
       └─ Tidak ada kabel → wlog("[Boot] No LAN cable") → lanjut WiFi langsung
WiFi mode (STA/AP/Config)
```

OLED menampilkan `"Checking cable..."` dan `"DHCP..."` selama proses.
