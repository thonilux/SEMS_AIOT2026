
Expected USB serial drivers depend on the ESP32 board:

| USB Chip | Driver |
| --- | --- |
| CP210x | Silicon Labs CP210x driver |
| CH340 / CH341 | WCH CH340 driver, currently detected on COM3 |
| Native USB ESP32-S3 | Usually no extra driver |
