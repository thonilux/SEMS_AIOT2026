# Journal — 2026-08-26

## Ringkasan

Sesi pendek, dua perbaikan firmware kecil pasca-release v1.0.0, langsung di-OTA ke device demo di `192.168.1.2`.

## 1. OLED Info Mode — Auto Timeout ke Dashboard

**Masalah:** Info Mode (manual paging halaman Device/WiFi/LAN/MQTT) di OLED dulu tetap nyangkut di sana sampai user manual hold 2 detik buat keluar. Kalau lupa keluar, layar stuck di halaman info terus, tidak balik ke Dashboard.

**Fix:** `firmware/src/main.cpp`
- Tambah `oledInfoIdleMs` + `kOledInfoTimeoutMs = 15000` (15 detik).
- Setiap tekan tombol di Info Mode (short-press next page) reset `oledInfoIdleMs`.
- Di `updateOled()`, kalau `oledInfoModeActive` dan idle sudah lewat 15 detik, otomatis `oledInfoModeActive = false`, balik ke `oledPage = 0` (Dashboard).

Commit: `b666d70` — "fix(oled): auto-exit Info Mode to dashboard after 15s idle"

## 2. Hapus Tombol BOOT (GPIO0) — Hardware Cuma 1 Tombol Fisik

**Konteks:** Kode lama asumsi 2 tombol fisik — `kBtnPin` (GPIO0/BOOT, active LOW, hold 3s untuk masuk config mode) dan `kBtn2Pin` (GPIO4, touch TTP223, multifungsi: short=next page, hold=masuk menu). User klarifikasi: hardware yang dipakai sekarang cuma **1 tombol fisik** (GPIO4). Tombol BOOT tidak terpasang/tidak dipakai di board demo ini.

**Fix:** Hapus total jalur GPIO0:
- `kBtnPin`, `kBtnHoldMs`, `btnPressedMs` — dihapus.
- `handleConfigButton()` — dihapus (fungsi + pemanggilan di `loop()`).
- `pinMode(kBtnPin, INPUT_PULLUP)` — dihapus dari `setup()`.
- `enterConfigMode()` tetap ada — masih dipanggil dari OLED Setting Menu (opsi "1. Boot Mode") via tombol tunggal GPIO4, jadi config mode tetap reachable tanpa GPIO0.

Commit: `3970f1d` — "fix(firmware): remove BOOT button (GPIO0), single physical button only"

## 3. Build + OTA

- Build lokal `pio run -e esp32dev` sukses kedua kali (RAM 17.3%, Flash 20.1%, tidak berubah signifikan).
- OTA langsung ke device demo: `curl -F "image=@firmware.bin" http://192.168.1.2/update` → `HTTP 200`.
- Device reboot otomatis, verifikasi balik online (`GET /` → `200`) ~8 detik kemudian.
- Firmware gabungan kedua fix ini sudah **live** di `192.168.1.2`.
