# Documentation

Project documentation is grouped by engineering domain.

```text
docs/
├── architecture/  Firmware architecture, roadmap, design decisions
├── hardware/      ESP32, LCD, RS485, relay, and electrical notes
├── api/           MQTT, web API, and payload contracts
└── operations/    Flashing, deployment, recovery, and maintenance guides
```

Keep design documents here instead of mixing them with firmware source files.
